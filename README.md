# ConnectNow 📹

> Real-time video conferencing mobile app
> built with Flutter & Firebase + Agora SDK

## ✨ Features
- 🎥 Real-time video & audio calling
- 💬 In-app chat messaging
- 🔐 Firebase Authentication (Login/Signup)
- 👥 Multi-user meeting room support
- 📅 Schedule & join meetings
- 📱 Works on Android & iOS

## 🛠 Tech Stack
- **Flutter & Dart**
- **Firebase** (Auth, Firestore, Realtime DB)
- **Agora SDK** (Real-time video calling)
- **State Management:** Provider

## 🚀 Run Locally
git clone https://github.com/shadowmonarch077/ConnectNow
cd ConnectNow
flutter pub get
flutter run
